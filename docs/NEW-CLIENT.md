# Демо під новий заклад — 20 хвилин

## 1. Зібрати дані (10 хв, безконтактно)

Тільки з їхнього ж сайту, картки Google і каталогів. **У заклад не звертаємось**
(D-010): ні записом, ні дзвінком, ні в Direct.

Потрібно: назва · категорія й місто · адреса · години · послуги з цінами ·
як вони називають виконавця (майстер / лікар / пост / тренер).

**Цін не вигадувати.** Немає на сайті — пиши `"за оглядом"` або `"—"`.
Вигадана ціна в демо це найшвидший спосіб втратити довіру на першій же зустрічі.

## 2. Профіль

```bash
cp clients/_template.json clients/<slug>.json
```

`<slug>` — латиницею, через дефіс: `mega-servis`, `your-style`.

Поля з підкресленням (`_mode`, `_workdays`) — це підказки, їх можна лишити,
збірка їх ігнорує.

## 3. Зібрати й подивитись

```bash
npm run build -- <slug>
```

Відкрити `dist/<slug>/index.html` **з телефона**, не з ноутбука.

## 4. Перевірити перед відправкою

- [ ] Назва, адреса й години збігаються з їхніми даними
- [ ] Послуги — їхні справжні, ціни не вигадані
- [ ] Стрічка «це демонстрація» на місці
- [ ] У шапці `noindex` — демо не має потрапити в пошук
- [ ] Відкривається за 2 секунди з мобільного інтернету
- [ ] Перший екран показує вибір послуги без прокрутки
- [ ] Екран підтвердження показує три повідомлення

## 5. Викласти

Див. `DEPLOY.md`. Посилання на демо йде в лист.

## Чого не робити

- Не ставити логотип закладу і не копіювати їхній стиль так, щоб сторінку
  можна було сплутати зі справжньою. Це демонстрація, а не підробка
- Не прибирати стрічку «демонстрація», поки не куплено й не запущено
- Не вигадувати послуги, яких у них немає
