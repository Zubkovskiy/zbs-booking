# Публікація

## GitHub Pages (для демо)

Гілка `main`, робочий процес у `.github/workflows/pages.yml` збирає й публікує
`dist/`. Демо буде за адресою:

```
https://<user>.github.io/zbs-booking/<slug>/
```

Демо мають `noindex, nofollow` — у пошук вони не потрапляють.

## Бойова версія (клієнт заплатив)

1. У профілі: `"mode": "live"` і `"apiBaseUrl": "https://api…"`
2. Домен `zapys.<домен клієнта>` — **оформлений на клієнта** (D-013),
   ми маємо доступ, не власність
3. На їхньому сайті міняється один рядок: кнопка «Онлайн запис» веде сюди (D-014)
4. Те саме посилання — у біо Instagram, у картку Google, у боти

## Перевірка перед здачею

`pagespeed.web.dev`, режим **Mobile**. Нижче 90 — не здаємо.
Це не побажання: ми продаємо швидкість, і клієнт може перевірити її сам.
